Symbolic AI

Two labs in logic: a knowledge base written as Datalog rules, then the same kind of question answered instead as a constraint model.

The labs

Lab1 Datalog A 45-rule loan knowledge base, a Game of Thrones family tree, and shortest journeys through a train network, all queried in pyDatalog. Lab2 Constraint programming N-queens, a Sudoku solver, a cryptarithmetic puzzle and family queries, all built as constraint models in Google OR-Tools.

Reading it

Source The folder on GitHub Two lab folders, each with its completed work once the lab is done. README The course README The full table of labs across both halves of Introduction to AI, what each is solved with, and what is provided going in.

The lab subjects and the datasets are not redistributed here. Each lab keeps them on disk, out of the repository; what is committed is the work written against them.
