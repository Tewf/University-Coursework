# Project Euler 345, matrix sum

Model Project Euler's problem 345 (the maximum matrix sum) as a mathematical program, with the matrix loaded from `data1.dat`.

The statement itself is just a link to projecteuler.net/problem=345 and an image (`assets/euler345.jpg`) that was not included in the download.

## Running it

This is a Caseine VPL exercise: the graded run happens on Caseine's own CPLEX grader, and `configExe` names the model it runs. To check a model locally, open it in IBM's free OPL/CPLEX IDE, or run it from the command line with `oplrun`, if installed.
