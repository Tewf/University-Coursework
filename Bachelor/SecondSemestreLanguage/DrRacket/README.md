# DrRacket – Functional Programming

This folder contains assignments for an introduction to functional programming using Racket (a Scheme dialect). Files include:

- `g1-td1.rkt`, `g1-td2.rkt`, … – exercises exploring recursion, list processing, higher‑order functions, and syntax.
- `g1-TD-exam22-23.rkt` – practice exam questions.
- `dm.rkt` – a mini‑project.
- `DrRacket_cleaned.zip` – a cleaned archive of all exercises.

## Running the exercises

Install [Racket](https://racket-lang.org). You can open the files in the DrRacket IDE or run them from the command line:

```sh
racket g1-td1.rkt
```

Follow the comments in each file for guidance. Implement functions as specified and test them in the REPL.

## What I learned

Functional programming teaches a different way of thinking about code. These exercises improved my skills in recursion, immutable data structures, and higher‑order functions.
