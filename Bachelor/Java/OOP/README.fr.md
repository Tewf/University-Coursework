# Programmation Orientee Objet (POO)

> [Read in English](README.md) · [Ouvrir sur le site ↗](https://tewf.github.io/University-Coursework/Bachelor/Java/OOP/)

**Cours :** POO, Licence MIASHS, Universite Grenoble Alpes

Exercices progressifs et mini-projets couvrant les concepts fondamentaux de la programmation orientee objet en Java.

## Ce que vous apprendrez

- Conception de classes, encapsulation et modificateurs d'acces
- Heritage, polymorphisme et redefinition de methodes
- Interfaces et classes abstraites
- Generiques et framework de collections Java
- Gestion des exceptions et entrees/sorties fichiers
- Application de design patterns a des problemes concrets

## Execution

```sh
javac -d bin $(find src -name '*.java')
java -cp bin package.ClassName
```

## Prerequis

- Syntaxe Java de base (variables, conditions, boucles)
- Aucune experience POO prealable requise
