\begin{abstract}
A $W\times H$ area is turned into a maze by recursive division. The generator
returns the maze twice: as a graph of cells joined by doors, and as a binary
tree of the divisions that built it. The graph is solved with A*, the tree with
a lowest-common-ancestor descent. Both return the unique route; the tree
examines thirty times fewer nodes.
\end{abstract}
