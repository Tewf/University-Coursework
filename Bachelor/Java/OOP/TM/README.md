# Travaux Mise en pratique (TM) – OOP

This folder contains mini‑projects designed to apply object‑oriented concepts learned in the course. Each assignment requires designing classes and interactions to solve more complex problems.

## Structure

- `src` – Java source files for each mini‑project.
- `bin` – Compiled class files.

Compile with `javac`:

```sh
javac -d bin $(find src -name '*.java')
```

These projects challenged me to design coherent APIs, apply design patterns, and write maintainable code.
