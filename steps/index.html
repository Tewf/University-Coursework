Step by step

The steps this practical asks for. Each one records what was tried, what was rejected, and the reference that settled it.

  1. Read the instance format

    Parse TSPLIB files: NODE_COORD_SECTION for coordinates and the lower-diagonal form for explicit distance matrices.

    Status
    Not started.

  2. Build the distance matrix

    Turn an instance into the matrix every algorithm below consumes, so the solvers never touch the file format.

    Status
    Not started.

  3. Trivial method

    Output the vertices in plain ascending index order as a placeholder tour, to prove the read-solve-write pipeline runs before any real algorithm exists.

    Status
    Not started.

  4. Held-Karp

    The exact solver: dynamic programming over (vertex, subset) pairs, growing from single vertices to the full set to read off the optimal round trip.

    Status
    Not started.

  5. A heuristic

    An approximate method, for instances the exact one cannot reach.

    Status
    Not started.

  6. Performance evaluation

    Execution time and tour length against instance size, on the provided TSPLIB benchmarks and on instances from instance_generator.py, written up with figures.

    Status
    Not started.
