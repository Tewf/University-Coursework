# Lab1: Datalog rule bases, family trees and journeys

Facts and rules in pyDatalog, from a bank's loan-approval rule base to a Game
of Thrones family tree to shortest train journeys across France.

## State

Not started.

## What the handout provides

`Lab1-datalog.pdf` is the subject; `Datalog-Rules.pdf` is a separate rule
base referenced from question 4. `familyTree.py` and `test-pyDatalog.py` are
starter scripts, and `got.csv`/`trains.csv` are the datasets they load.
`familyTree.py` already builds the family-tree objects; the predicates it
asks for go in a module of my own that imports it, never inside the staff's
file itself.

## Running it

```bash
conda activate m1ai-intro-ai
```

`pyDatalog` is already declared in the course's `environment.yml`.
