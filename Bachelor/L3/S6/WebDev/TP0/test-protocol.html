Ce que tu vas apprendre dans ce cours

  • HTML - La structure des pages web (le squelette)
  • CSS - La mise en forme et le design (les vêtements)
  • JavaScript - L'interactivité et la logique (le cerveau)
  • Le DOM - Modifier les pages avec JavaScript
  • Node.js - JavaScript côté serveur
  • Express - Un framework pour créer des serveurs web

Comment vérifier que tout fonctionne ?

  1. Tu vois cette page dans ton navigateur
  2. Le texte s'affiche correctement (pas de symboles bizarres)
  3. Les accents marchent : é è à ç ù ê î ô û
  4. Tu peux ouvrir les outils de développement (touche F12)
