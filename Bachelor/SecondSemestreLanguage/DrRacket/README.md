# DrRacket — Functional Programming

> [Lire en francais](README.fr.md)

**Course:** Functional Programming — Licence MIASHS, Universite Grenoble Alpes

An introduction to functional programming using Racket (a Scheme dialect). Exercises progress from basic recursion to higher-order functions and symbolic computation.

## What You'll Learn

- Recursive thinking and recursive data structures
- List processing (map, filter, fold patterns)
- Higher-order functions and closures
- Symbolic computation and expression manipulation
- Functional design patterns vs. imperative approaches

## Files

| File | Topic |
|------|-------|
| `g1-td1.rkt` | Basic Racket syntax, simple functions |
| `g1-td2.rkt` | Recursion on numbers and lists |
| `g1-td3.rkt` | Higher-order functions, map/filter |
| `g1-td4.rkt` | Advanced list processing |
| `g1-td5.rkt` | Symbolic computation, trees |
| `g1-TD-exam22-23.rkt` | Practice exam questions |
| `dm.rkt` | Mini-project |

## Running the Exercises

Install [Racket](https://racket-lang.org), then open files in DrRacket IDE or run from terminal:

```sh
racket g1-td1.rkt
```

Follow comments in each file. Implement functions and test in the REPL.

## Prerequisites

- No prior functional programming experience needed
- Basic programming concepts (variables, conditions, loops)
