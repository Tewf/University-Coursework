📘 Aide-Mémoire HTML - Guide de Référence Rapide

1. Structure de Base d'une Page HTML

<!DOCTYPE html>
<html lang="fr">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Titre de la Page</title>
  </head>
  <body>
    <!-- Votre contenu ici -->
  </body>
</html>
💡 Astuce : Tapez ! puis Tab dans VS Code pour générer automatiquement cette structure.

2. Balises de Texte

Balise Description Exemple
<h1> à <h6> Titres (h1 = plus important, h6 = moins important) <h1>Titre Principal</h1>
<p> Paragraphe <p>Un paragraphe de texte.</p>
<br> Saut de ligne (auto-fermante) Ligne 1<br>Ligne 2
<hr> Ligne horizontale de séparation <hr>
<strong> Texte important (gras + sémantique) <strong>Important!</strong>
<em> Texte accentué (italique + sémantique) <em>Accentué</em>
<b> Texte en gras (sans sens sémantique) <b>Gras</b>
<i> Texte en italique (sans sens sémantique) <i>Italique</i>
<small> Texte en petits caractères <small>Texte fin</small>
<mark> Texte surligné <mark>Surligné</mark>
⚠️ Attention : Préférez <strong> et <em> à <b> et <i> pour l'accessibilité.

3. Listes

Liste Non Ordonnée (puces)

<ul>
  <li>Premier item</li>
  <li>Deuxième item</li>
  <li>Troisième item</li>
</ul>

Liste Ordonnée (numéros)

<ol>
  <li>Premier</li>
  <li>Deuxième</li>
  <li>Troisième</li>
</ol>

Liste de Description

<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets</dd>
</dl>

4. Liens

Type de Lien Code
Lien interne (même site) <a href="page.html">Lien</a>
Lien vers une ancre <a href="#section">Aller à</a>
Lien externe <a href="https://..." target="_blank" rel="noopener">Site</a>
Lien email <a href="mailto:email@example.com">Email</a>
Lien téléphone <a href="tel:+33123456789">Appeler</a>
💡 Astuce : Pour les liens externes, ajoutez toujours target="_blank" et rel="noopener noreferrer" pour la sécurité.

5. Images

<img src="chemin/image.jpg" alt="Description de l'image" width="300" height="200">
Attribut Description Obligatoire?
src Chemin vers l'image ✅ Oui
alt Texte alternatif (accessibilité) ✅ Oui
width Largeur en pixels ❌ Non
height Hauteur en pixels ❌ Non

Image Cliquable

<a href="page.html">
  <img src="logo.png" alt="Logo">
</a>

Fusion de Cellules

Attribut Description Exemple
colspan Fusion horizontale (colonnes) <td colspan="3">...</td>
rowspan Fusion verticale (lignes) <td rowspan="2">...</td>

7. Balises Sémantiques HTML5

Balise Utilisation
<header> En-tête de page ou de section
<nav> Section de navigation (menu)
<main> Contenu principal (un seul par page)
<section> Section thématique de contenu
<article> Contenu autonome (article de blog, produit, etc.)
<aside> Contenu connexe (barre latérale)
<footer> Pied de page
⚠️ Attention : Préférez les balises sémantiques (<nav>, <section>) aux <div> génériques pour une meilleure accessibilité.

10. Attributs Globaux (utilisables sur presque toutes les balises)

Attribut Description Exemple

12. ✅ Bonnes Pratiques HTML

  1. Un seul <h1> par page - C'est le titre principal
  2. Toujours inclure l'attribut alt sur les images - Pour l'accessibilité
  3. Indenter correctement le code - Pour la lisibilité
  4. Fermer toutes les balises - Même si certains navigateurs sont tolérants
  5. Utiliser des balises sémantiques - <nav> plutôt que <div class="nav">
  6. Valider votre HTML - Utilisez https://validator.w3.org/
  7. Noms de fichiers en minuscules - index.html, pas Index.HTML
  8. Pas d'espaces dans les noms de fichiers - mon-fichier.html, pas mon fichier.html
  9. UTF-8 pour l'encodage - Toujours inclure <meta charset="UTF-8">
  10. Séparer structure (HTML), style (CSS) et comportement (JS)
