# SQL Practical Work

This directory contains practical exercises (TP) for the Databases course. Each `.sql` file corresponds to a worksheet in the course, and the associated `.pdf` provides the assignment instructions.

Course materials and instructions are available at: https://pellierd.github.io/homepage/teaching/databases/

## Contents

- `tp01.sql` / `tp01.pdf` – introduction to relational schemas, creating tables, and basic SELECT queries.
- `tp02.sql` / `tp02.pdf` – joins, set operations, and nested queries.
- `tp03.sql` / `tp03.pdf` – aggregation, grouping, and HAVING clauses.
- `tp04.sql` / `tp04.pdf` – transactions, views, and additional practice.
- `bd/` – database files used in the practicals.

## Running the scripts

You can run the SQL files in any standard relational database system such as PostgreSQL, MySQL, or SQLite. Create the database defined in `bd/`, then execute each `tpXX.sql` file to perform the tasks. Compare your results with the expected outputs described in the PDFs.

## Skills gained

These practicals taught me how to design relational schemas, write complex queries, and manipulate data sets – foundational skills for data analysis and back‑end development.
