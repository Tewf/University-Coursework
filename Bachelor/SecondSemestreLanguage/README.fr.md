# Langages de programmation & Paradigmes

> [Read in English](README.md) · [Ouvrir sur le site ↗](https://tewf.github.io/University-Coursework/Bachelor/SecondSemestreLanguage/)

**Cours :** Modules de langages du second semestre, Licence MIASHS, Universite Grenoble Alpes

Trois cours exposant les etudiants a des paradigmes de programmation fondamentalement differents, elargissant les approches de resolution de problemes au-dela de la programmation imperative traditionnelle.

## Ce que vous apprendrez

- **Programmation fonctionnelle** : Penser en termes de fonctions pures, recursion et donnees immutables
- **Programmation logique** : Exprimer les problemes comme des faits et regles, laisser le moteur trouver les solutions
- **Bases de donnees relationnelles** : Modeliser les donnees avec des schemas, interroger avec SQL

## Cours

| Paradigme | Langage | Dossier | Concepts cles |
|-----------|---------|---------|---------------|
| **Fonctionnel** | Racket (Scheme) | [DrRacket/](DrRacket/) | Recursion, fonctions d'ordre superieur, traitement de listes, closures |
| **Logique** | Prolog | [Prolog/](Prolog/) | Faits, regles, backtracking, unification, raisonnement |
| **Relationnel** | SQL | [SQL/](SQL/) | Schemas, SELECT, JOIN, agregation, transactions |

## Pourquoi etudier plusieurs paradigmes ?

Chaque paradigme enseigne une facon differente de decomposer les problemes :

```
Imperatif (Java)    → Instructions pas a pas
Fonctionnel (Racket) → Composer des transformations sur les donnees
Logique (Prolog)     → Declarer des relations, interroger les solutions
Relationnel (SQL)    → Decrire quelles donnees on veut, pas comment les obtenir
```

Cette diversite fait de vous un programmeur plus polyvalent et approfondit votre comprehension du calcul lui-meme.

## Prerequis

- Experience de programmation de base dans n'importe quel langage
- Aucune connaissance prealable en programmation fonctionnelle, logique ou bases de donnees requise
