# Dossier home/

Ce dossier doit contenir les fichiers SVG et images utilisés par le site.

## Fichiers nécessaires

Copie ces fichiers depuis le dossier `../TP1/home/` :
- `cv.svg` - Icône de CV
- `mail.svg` - Icône d'email
- `ufr.svg` - Logo de l'université

Et ajoute ta photo de profil :
- `photo.jpg` - Ta photo (optionnel, copie depuis `../TP1/my-picture.png`)

## Commande pour copier

```bash
cp ../TP1/home/*.svg home/
cp ../TP1/my-picture.png home/photo.jpg
```
