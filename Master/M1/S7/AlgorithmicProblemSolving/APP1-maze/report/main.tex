\begin{abstract}
Minos wants mazes that nobody can predict from a blueprint, with a single exit
and a route out from anywhere inside. This report turns that request into a
graph problem, builds the maze by recursive division so that the object
produced is a spanning tree of the grid graph, then reads the escape route off
that tree. Giving every door unit length makes the tree metric the number of
doors crossed, which is what the shortest-path search of
Section~\ref{sec:shortest-path} measures and what the Manhattan and Euclidean
distances are compared against as heuristic guidance. A Python implementation
is used to check the claims on generated instances, and the closing section
puts costs on the data structure and on both algorithms.
\end{abstract}
