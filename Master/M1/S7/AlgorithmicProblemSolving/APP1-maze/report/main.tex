\begin{abstract}
A rectangular area of $W\times H$ cells is laid out as a maze by recursive
division: a full wall across the longest dimension, exactly one door in it, and
the same rule inside each of the two halves. This report states that as a graph
problem, shows that the requirements force the maze to be a spanning tree of
the grid graph, and derives a generation algorithm together with the data
structure it runs on and a proof that what it returns is that spanning tree.
Giving every door unit weight makes the length of a route the number of doors
crossed, which is what the shortest-path search of
Section~\ref{sec:shortest-path} minimises and what the Manhattan and Euclidean
distances are compared against as heuristic guidance. A Python implementation
checks the claims on generated instances, and the closing section gives the
size of the structure and the cost of both algorithms.
\end{abstract}
