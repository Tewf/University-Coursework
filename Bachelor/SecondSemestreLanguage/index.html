Three paradigms, one block

Functional, logic and relational programming, taught together. The point of the block is contrast: the same problem is a recursion, a set of rules, or a query, depending on which room you are in.

Racket Functional programming Pure functions, recursion and immutable data. Prolog Logic programming Declare facts and rules, then ask questions and let the engine search. SQL Relational databases Schemas, joins, set operations, aggregation, transactions and views.
