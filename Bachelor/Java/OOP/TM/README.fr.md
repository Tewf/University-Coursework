# Mini-Projets (TM) — POO

> [Read in English](README.md)

Mini-projets concus pour appliquer les concepts orientee objet a des problemes plus substantiels. Chaque devoir demande de concevoir des classes, des interactions et des API coherentes.

## Execution

```sh
javac -d bin $(find src -name '*.java')
java -cp bin package.ClassName
```
