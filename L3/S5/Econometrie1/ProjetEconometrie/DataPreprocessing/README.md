# Prétraitement des Données

Ce dossier contient tous les fichiers nécessaires pour le prétraitement et la préparation des données.

## Fichiers

- **DataPreparation.ipynb** : Carnet Jupyter principal pour la préparation des données
- **DataPreparationPanel.ipynb** : Carnet Jupyter complémentaire pour l'analyse avec panneaux de données
- **DataDocumentation/** : Documentation détaillée sur les données
- **PreprocessedData/** : Données traitées et nettoyées prêtes pour la modélisation

## Contenu

Les carnets effectuent :
- Chargement et exploration initiale des données
- Nettoyage et gestion des valeurs manquantes
- Transformation des variables
- Création de variables de contrôle
- Exportation des données prétraitées
