# Résumé de la Revue de Littérature

Ce dossier contient le résumé et la synthèse de la revue bibliographique.

## Fichiers

- **resume.tex** : Document LaTeX avec le résumé complet de la revue

## Contenu

Le résumé inclut :
- Introduction aux enjeux du marché immobilier
- Synthèse des approches théoriques
- Résumé des études empiriques pertinentes
- Méthodologies et approches retenues
- Conclusion et positionnement du projet

## Format

Le fichier est en LaTeX et peut être compilé pour générer un document PDF.

## Compilation

Pour générer le PDF :
```bash
pdflatex resume.tex
```

## Utilisation

Ce document sert de fondation théorique pour :
- Justifier la spécification du modèle
- Interpréter les résultats
- Contextualiser les découvertes empiriques
