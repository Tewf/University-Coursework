\begin{abstract}
A rectangular area of $W\times H$ cells is laid out as a maze by recursive
division: a full wall across a dimension, exactly one door in it, and the same
rule inside each of the two halves. The requirements force the result to be a
spanning tree of the grid graph, and the generator returns it \emph{twice}: as
a graph of cells joined by doors, and as a binary tree recording which division
made which sub-maze. Each structure has its own way out. The graph is searched
with Dijkstra's algorithm, every door costing one step; the tree is read with a
lowest-common-ancestor descent, which never touches a cell. Both return the
same route --- the maze is a tree, so there is only one --- so what separates
them is how much they examine, and the tree wins by a factor of thirty. A C
implementation measures every claim, and the closing section puts costs on all
of it and against the literature.
\end{abstract}
