# DrRacket : Programmation fonctionnelle

> [Read in English](README.md)

**Cours :** Programmation fonctionnelle, Licence MIASHS, Universite Grenoble Alpes

Une introduction a la programmation fonctionnelle en Racket (un dialecte de Scheme). Les exercices progressent de la recursion de base aux fonctions d'ordre superieur et au calcul symbolique.

## Ce que vous apprendrez

- Pensee recursive et structures de donnees recursives
- Traitement de listes (patterns map, filter, fold)
- Fonctions d'ordre superieur et closures
- Calcul symbolique et manipulation d'expressions
- Patterns de conception fonctionnels vs. approches imperatives

## Fichiers

| Fichier | Theme |
|---------|-------|
| `g1-td1.rkt` | Syntaxe Racket de base, fonctions simples |
| `g1-td2.rkt` | Recursion sur les nombres et les listes |
| `g1-td3.rkt` | Fonctions d'ordre superieur, map/filter |
| `g1-td4.rkt` | Traitement avance de listes |
| `g1-td5.rkt` | Calcul symbolique, arbres |
| `g1-TD-exam22-23.rkt` | Questions d'examen blanc |
| `dm.rkt` | Mini-projet |

## Executer les exercices

Installer [Racket](https://racket-lang.org), puis ouvrir les fichiers dans l'IDE DrRacket ou lancer depuis le terminal :

```sh
racket g1-td1.rkt
```

Suivre les commentaires dans chaque fichier. Implementer les fonctions et tester dans le REPL.

## Prerequis

- Aucune experience prealable en programmation fonctionnelle requise
- Concepts de programmation de base (variables, conditions, boucles)
