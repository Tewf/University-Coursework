# Entraînement de Modèles

Ce dossier contient les scripts et carnets pour l'entraînement et l'évaluation des modèles économétriques.

## Fichiers

- **LinearRegression.ipynb** : Carnet pour la régression linéaire
- **LinearRegression.md** : Documentation et résultats de la régression linéaire
- **Extension/** : Modèles avancés et extensions

## Modèles Disponibles

### Modèle Principal
- **Régression Linéaire** : Modèle de base pour l'analyse des prix de vente

### Extensions
- **Random Forest** : Approche par apprentissage machine pour la prédiction

## Contenu des Carnets

- Chargement des données prétraitées
- Spécification du modèle
- Estimation des paramètres
- Tests statistiques
- Visualisation des résultats
- Évaluation des performances

## Résultats

Tous les résultats et interprétations sont documentés dans les fichiers .md correspondants.
