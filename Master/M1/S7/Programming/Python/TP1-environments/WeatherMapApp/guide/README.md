# Guide

Four short pages. Read them in order the first time; after that, jump straight
to the one you need.

| Page | Read it when |
|---|---|
| [How it works](how-it-works.md) | You want the whole journey, from the API call to the pixels on screen. |
| [The two windows](the-two-windows.md) | You are wondering why there are two versions of the same map, and which one to copy. |
| [Reusing the code](reusing-the-code.md) | You want to lift a piece of this into your own project. |
| [The maths](the-maths.md) | You want to know how twelve measurements become a smooth map. |

Everything here describes code in the folder above. If a page and the code ever
disagree, the code is right — start from the module's own docstring, which is
always the most specific description of what it does.
