2.2 Feature Engineering par familles olfactives

Plutôt que d’extraire les notes individuelles les plus fréquentes (approche arbitraire), nous regroupons accords et notes par famille olfactive selon une roue des parfums. Cette approche est soutenue par Kumar et al. (2015) qui montrent que les descripteurs olfactifs se regroupent naturellement en communautés perceptuelles (« fruit », « floral », « wood », « sweet », « green » sont des hubs dominants dans toutes les bases de données étudiées). Nos 10 familles : Citrus, Green, Aquatic, Floral, Fruity, Spicy, Woody, Gourmand, Leather/Smoky, Powdery/Amber.

2.2.1 Accords → familles

Chaque accord (mainaccord1 à mainaccord5) est mappé vers sa famille. Les accords non reconnus → “autre”.

Code 
accord_cols <- c("mainaccord1", "mainaccord2", "mainaccord3", "mainaccord4", "mainaccord5")
data_rated <- map_accords_to_families(data_rated, accord_cols)

fam_cols <- grep("^fam_", names(data_rated), value = TRUE)
fam_sums <- colSums(data_rated[fam_cols])
fam_df <- data.frame(
  Famille = gsub("^fam_", "", names(fam_sums)),
  Effectif = fam_sums,
  Pct = round(fam_sums / nrow(data_rated) * 100, 1)
)
fam_df <- fam_df[order(-fam_df$Effectif), ]
rownames(fam_df) <- NULL
kable(fam_df, col.names = c("Famille", "Parfums", "%"), booktabs = TRUE)

Les familles woody, gourmand et floral couvrent la majorité des parfums, cohérent avec les tendances du marché.

2.2.2 Notes → familles

Chaque note individuelle (tête, cœur, fond) est classée par correspondance de mots-clés → 30 indicatrices (10 familles x 3 phases).

Code 
data_rated <- map_notes_to_families(data_rated, "Top", prefix = "top_")
data_rated <- map_notes_to_families(data_rated, "Middle", prefix = "mid_")
data_rated <- map_notes_to_families(data_rated, "Base", prefix = "base_")
cat("Indicatrices créées : Tête", length(grep("^top_", names(data_rated))),
    "| Coeur", length(grep("^mid_", names(data_rated))),
    "| Fond", length(grep("^base_", names(data_rated))), "\n")

2.3.2 Country (regroupement < 5%)

Les pays rares sont regroupés en “Autre” pour éviter des indicatrices trop creuses.

Code 
data_rated <- merge_rare_categories(data_rated, "Country", threshold_pct = 5)

country_freq <- data_rated %>%
  filter(!is.na(Country)) %>%
  count(Country, sort = TRUE) %>%
  mutate(Pct = round(n / sum(n) * 100, 1))
kable(country_freq, col.names = c("Pays", "Effectif", "%"), booktabs = TRUE)
countries_kept <- country_freq$Country
for (country in countries_kept) {
  col_name <- paste0("country_", make.names(country))
  data_rated[[col_name]] <- as.integer(data_rated$Country == country & !is.na(data_rated$Country))
}

2.5 Imputation et split

L’imputation par la médiane est robuste aux valeurs extrêmes (Rating_Count).

Code 
preprocess_median <- preProcess(df_model[, feature_cols], method = "medianImpute")
df_model[, feature_cols] <- predict(preprocess_median, df_model[, feature_cols])

set.seed(42)
train_index <- createDataPartition(df_model$Satisfaction, p = 0.7, list = FALSE)
train_data <- df_model[train_index, ]
test_data <- df_model[-train_index, ]

kable(data.frame(
  Ensemble = c("Train", "Test"),
  Observations = c(nrow(train_data), nrow(test_data)),
  Pct_Oui = c(round(mean(train_data$Satisfaction == "Oui"), 3),
               round(mean(test_data$Satisfaction == "Oui"), 3))
), col.names = c("Ensemble", "Observations", "Prop. Oui"), booktabs = TRUE)

2.6 Choix des classifieurs

Données binaires/numériques, cible équilibrée, pas de valeurs manquantes → deux classifieurs complémentaires :

  1. Régression logistique (Elastic Net) : baseline interprétable, sélection automatique de variables par régularisation.
  2. Forêt aléatoire : capture les interactions non-linéaires entre familles olfactives, classement d’importance des variables.

Métrique principale : AUC (capacité discriminante indépendante du seuil).
