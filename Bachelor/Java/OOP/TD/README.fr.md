# Travaux Diriges (TD) : POO

> [Read in English](README.md)

Exercices cibles du cours de programmation orientee objet, chacun portant sur un concept specifique :

- Creation de classes et encapsulation
- Heritage et polymorphisme
- Interfaces et classes abstraites
- Generiques et collections
- Gestion des exceptions et entrees/sorties fichiers

## Execution

```sh
javac -d bin $(find src -name '*.java')
java -cp bin package.ClassName
```
