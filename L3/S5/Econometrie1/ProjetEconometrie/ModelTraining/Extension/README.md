# Extensions de Modèles

Ce dossier contient les modèles étendus et les approches complémentaires au modèle de régression linéaire de base.

## Fichiers

- **RandomForest.ipynb** : Carnet pour l'entraînement du modèle Random Forest
- **ModelTraining_Extension_RandomForest.md** : Documentation et résultats

## Approches Explorées

### Random Forest
- Modèle d'apprentissage machine basé sur les arbres de décision
- Gestion automatique des interactions entre variables
- Robustesse aux valeurs aberrantes
- Importance des variables

## Comparaison

Ces modèles sont comparés au modèle de régression linéaire en termes de :
- Performance de prédiction
- Interprétabilité
- Complexité du modèle
- Applicabilité économétrique

## Utilisation

Consulter les carnets pour :
- La méthodologie détaillée
- Les résultats comparatifs
- Les recommandations sur le choix du modèle
