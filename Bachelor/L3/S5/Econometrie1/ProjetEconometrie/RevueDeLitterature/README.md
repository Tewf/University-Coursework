# Revue de Littérature

Ce dossier contient la revue bibliographique et l'état de l'art sur le sujet du projet.

## Contenu

- **resume/** : Résumé et synthèse de la revue de littérature

## Objectifs

La revue de littérature couvre :
- Les théories économiques fondamentales
- Les travaux empiriques précédents
- Les méthodologies utilisées dans les études similaires
- Les lacunes dans la littérature existante
- La justification de notre approche

## Structure

Cette section fournit le contexte théorique pour :
- Justifier le choix des variables
- Interpréter les résultats empiriques
- Positionner le projet par rapport aux travaux existants

## Utilisation

Consulter cette revue avant de lire les résultats pour comprendre :
- Le cadre conceptuel du projet
- Les hypothèses testées
- La pertinence de la méthodologie retenue
